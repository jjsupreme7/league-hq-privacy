# The League privacy policy

Public privacy-policy and support page for the private mobile app **The League**.

- Privacy policy: https://jjsupreme7.github.io/league-hq-privacy/
- Support: https://jjsupreme7.github.io/league-hq-privacy/#support

The support section includes the public FantasyCalc credit as a plain HTML link.
